# Aldwyn Labs website guidance

Preserve the selected extended interlocking AL SVG master and dark palette: aubergine #211729, plum #30223D, iris #A789F5, text #F4F0F7 and muted #C4B9D0. Use aubergine text on iris buttons. Manrope headings and Inter body type are proposed pending founder review.

This is a first template, not a production release. No domain, business contacts, repository-to-Codex Cloud connection or live enquiry integration has been confirmed. Do not publish, purchase services or change DNS without explicit authorization.

Keep the site buildless unless a real requirement justifies dependencies. Preserve native links, details, labels, visible focus and reduced-motion support. Do not add client claims, testimonials, invented prices or unconfirmed contact details.

The project form prepares a brief locally. Never send fields through GET or a remote endpoint, and never imply enquiry delivery. Keep submission disabled in source HTML until JavaScript handlers are installed. A real contact flow needs separately agreed handling.

Run `npm run check` after JavaScript changes. Verify internal links and assets. Use the supported Work preview for desktop and mobile checks when available. Record limitations honestly. Keep changes on a review branch until approved.
